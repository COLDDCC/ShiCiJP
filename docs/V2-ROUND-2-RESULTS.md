# V2 第 2 轮：N5 静态词库

日期：2026-10-26。范围：分类入口、独立词条、可抓取正文与部署生成。

## 实际交付

- `/jlpt/vocabulary/n5/`：总览，13 个分类入口。
- `/jlpt/vocabulary/n5/group-numbers/` 等分类页：日语、读音与中文义项；输入框可在本组筛选，禁用 JS 时仍可浏览完整列表。
- 718 个 `/jlpt/vocabulary/n5/w-<stable-hash>/` 词条页：读音、中文义项、日语例句、中文译文，默认显示“中文草稿 · 待审核”。
- 词条身份使用 expression + reading；异读同形词分别生成 URL。`鞄` 草稿映射到参考词条 `かばん`，不额外制造同义重复页面。
- 首页、学习中心、N5 指南及现有词库提供入口。首页到分类 2 次点击，分类到词条 1 次。
- 词条来源与审核说明可折叠；未把草稿覆盖率说成人工审校率。
- 从数据库统一导出生成页面；没有第二套手写中文内容源。

## 构建方式

`npm run build:n5-pages`：生成 public 下的 N5 静态 HTML，并扩充 sitemap，保留站内原有 URL。生成的 N5 HTML 不提交 git，GitHub Pages 在上传 public 前生成。每次构建重新读取数据库导出；过时的生成页面会被移除。

`npm run test:n5-pages`：在临时目录中验证输出，不依赖生成物已存在于仓库。

GitHub Pages 的发布步骤先执行同步检查、质量测试、页面测试，再生成 HTML；任何步骤失败均阻止上传与发布。

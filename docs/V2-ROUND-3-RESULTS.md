# V2 第 3 轮：搜索、词条与轻量复习

日期：2026-10-26。

## 实际交付

- 首页在文本分析区之后增加紧凑的学习入口：N5 快速查词、我的复习、N5 阅读。原有分析器仍在首屏顶部。
- 快速查词支持日语、假名、中文，显示最多 5 个候选，直接打开独立词条；提交表单可进入原有完整词库并保留查询。
- 每个 N5 词条提供“加入复习 / 移出复习”及“标记认识 / 撤销”。
- `/jlpt/review/` 每次显示一个词；默认隐藏答案，支持揭示释义和双语例句、再练一次、认识了、重新加入复习。
- 首页显示待复习数量；同一浏览器刷新保留记录、不同标签页同步状态。
- 新复习记录独立保存在 `shici.n5.review.v1`。不改写原分析器或旧版 JLPT 词卡的记录，不上传学习记录。不同浏览器/设备不自动同步。
- 存储不可用时明确提示；损坏记录不会被静默覆盖。词库加载失败时保留记录，并提供重试。
- 复习页属于本地个人工具，设为 noindex，不加入 sitemap；公开词条的可抓取正文保持不变。
- 搜索、原词库 N5 数据与复习页面共用部署时生成的数据库导出，不新增翻译内容源。
